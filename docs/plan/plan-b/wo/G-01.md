## G-1 — New repo bootstrap (specs in-tree, CI green on empty scaffold)

**Effort M (3–5d) · P0 · Depends: the new repository exists (owner created + named it).**
Prepend `shared/00_MASTER_CONTEXT.md`. Its repo-facts appendix describes the DELETED
Bid_it codebase — part of THIS order is regenerating that appendix for the new repo.

### Objective & value
An empty product cannot be built on; a scaffold with green CI, the specs in-tree and
the invariant gates armed means every later order lands on rails. This order creates
the rails.

### Scope
IN: repo layout, toolchain, CI, docker-compose dev env, spec migration, doc skeleton.
OUT: any business feature, any schema beyond an empty alembic baseline, auth, UI pages.

### Steps
1. Layout: `backend/` (FastAPI app skeleton: `app/models|core|services|api`, `tests/`),
   `frontend/` (Vite + React + TS + Tailwind init), `docs/`, `deploy/` (compose:
   postgres:16, redis:7, minio, mailpit), `.github/workflows/ci.yml`.
2. Copy the surviving knowledge from the old Bid_it branch `claude/bidit-invoice-data-analytics`
   `docs/plan/` → this repo `docs/plan/` (shared/, plan-b/, PLAN_A_vs_PLAN_B.md). This
   is a DOCS copy; copying CODE from the old repos is prohibited (Part A).
3. Backend toolchain: `pyproject.toml` (ruff, mypy --strict, pytest, pytest-asyncio),
   `requirements.txt` pinned; FastAPI `main.py` with `/healthz`; SQLAlchemy 2 async
   engine factory; alembic init with an EMPTY baseline revision.
4. Boundary test from day one: `tests/test_boundaries.py` — AST-walk imports, assert
   `models` imports nothing app-level, `core` never imports `services|api`, `services`
   never imports `api`.
5. CI jobs: lint (ruff check + format --check), typecheck (mypy strict — whole app),
   backend (pytest, SQLite), postgres (services: postgres:16 — runs alembic upgrade
   head + `alembic check` + the postgres-marked tests), frontend (npm ci + tsc + vite
   build), docker-build (both images). All required.
6. Config module: pydantic-settings; `validate_production()` crashes at boot on dev
   secret / non-postgres URL / wildcard CORS in production; API docs disabled in prod.
7. PII tripwire: port `scripts/pii_scan.py` job (structural patterns: EU-VAT regex +
   MOD-97 IBAN; plus the salted-hash deny-list if WO-6 Step 1 produced one) as a
   required CI job.
8. Regenerate the Part A appendix: write `docs/plan/shared/00_MASTER_CONTEXT.md`
   appendix section against THIS repo (commands, paths, fixtures) and mark the old
   facts superseded.
