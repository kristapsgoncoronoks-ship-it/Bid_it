## G-2 — Money + time core

**Effort S (2–3d) · P0 · Depends: G-1.** Prepend `shared/00_MASTER_CONTEXT.md`.

### Objective & value
Every euro the platform will ever compute flows through this module. Getting it right
once, with property tests, is what makes invariant "no float on money" enforceable.

### Scope
IN: `app/core/money.py`, `app/core/periods.py`, CI grep-gate. OUT: FX (own order), tax.

### Steps
1. `money.py`: `q2(Decimal)->Decimal` (ROUND_HALF_UP, 2dp), `q(value, exp)`,
   `sum2(iterable)` (Decimal-sum then q2), parsing from str/int only — passing a float
   RAISES `TypeError` deliberately.
2. `periods.py`: date helpers (month/quarter periods, add_months end-of-month-safe,
   ISO parsing, `today()` injectable for tests).
3. SQLAlchemy `Money` type decorator: `Numeric(14,2)` bound to Decimal, rejects float binds.
4. CI gate: a test that greps `app/` for `float(` in files importing money / models
   with Money columns, and for `round(` on money identifiers — fails on hit.
5. Property tests (hypothesis): q2 idempotent; sum2 order-independent; no drift
   summing 10k random amounts vs Decimal reference; add_months(2026-01-31, 1) == 2026-02-28.

### Acceptance criteria
- [ ] `money.q2(Decimal("2.005")) == Decimal("2.01")` (HALF_UP proven, not banker's).
- [ ] `money.q2(2.005)` raises TypeError (float rejected at the door).
- [ ] Property suite green; grep-gate job green and required.
